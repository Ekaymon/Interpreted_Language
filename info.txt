Every line starts with a library declaration - only 3 currently, s (standard), m (maths), and f (function)
Then a command within the library, such as out (print something to the terminal)
Then any inputs for that command

All separated by colons (:)

Standard library contains:
    out - output to console
    in - get user input and assign it to a variable
    var - create a variable
    if - run a function if a condition is true

Standard library usage:
    out:
        Outputs, on one line, to the console. Calling it on its own will output whatever follows as a string, adding the flag v will instead search for a variable called the value of the next field and output it.
        Several strings and variables can be stacked on one line.
        usage: s:out:Testing! :v:name would print the string "Testing! " to the terminal, then search for the value of a variable called "name" and print it, followed by a newline. 
    
    in:
        Outputs a prompt and assigns user input to a variable
        usage: s:in:enter a number:x would output "enter a number", allow the user to input something, and store the input in a variable called x

        the prompt is not an optional field, however can be left blank
        usage: s:in::x would simply allow the user to input something, without prompting first
    
    var:
        creates or updates a variable and gives it a name and a value. Values can be any data type
        usage: s:var:a:4 creates a variable called a and gives it the value 4
    
    if:
        has 2 options, mvars or single var:
            mvars:
                Compares two variables and runs the requested function if the condition is true
                usage: s:if:mvars:=:a:b:example compares the values of a and be to see if they are equal, then runs the function named example if they are
            single var:
                Compares a variable and a number and runs the requested function if the condition is true. The variable must always be passed as the second argument after the if:: call
                usage: s:if::=:a:4:example compares if the value of a equals 4, then runs the function named example if they are
        
        Also has optional else flag:
            Allows a different function to run if a check if not true
            usage: s:if:mvars:=:x:y:example1:else:example2 compares the values of variables x and y, if they are equal the function "example1" will run, if not "example2" will run

        Only numbers can be compared, strings will throw an error.

        There are 6 possible comparisons: 
            = (equal to)
            > (greater than)
            < (less than)
            >= (greater than or equal to)
            <= (less than or equal to)
            != (not equal to)

Maths library usage:
    Uses reverse Polish notation 
    e.g.: +:2:3 returns 5

    It has two modes: vars and regular

    vars:
        processes 2 variables, performing the operation listed and returning the result to the variable declared
        usage: m:vars:+:a:b:c adds variables a and b, and assigns it to variable c
    
    regular:
        processes 2 numbers, performing the operation listed and returning the result to the variable declared. Called using a blank keyword
        usage: m::+:3:4:c adds numbers 3 and 4 and assigns the result to variable c

    variable and non-variable operations cannot be mixed, so if it is necessary the non-variable value should be assigned to a new variable and variable operations used

    There are 5 operations available:
        + (addition)
        - (subtraction)
        * (multiplication)
        / (division)
        ^ (powers)

Functions library contains:
    def - create a function
    call - call a previously created function

Functions library usage:
    def:
        creates a function, assigns it a name, and declare what code it contains. A function can contain unlimited commands, however they must all be on one line and separated using & as a delimeter
        usage: f:def:hello:s:out:hello:&:s:out:world creates a function called hello, which contains the lines of code s:out:hello and s:out:world (output the string hello to the console, then output the string word on a new line)
    
    call:
        calls a previously created function, running the code contained inside
        usage: f:call:test calls the custom function named test

Graphics library contains:
    spawnwindow - spawns a window with the win32 api
    changepixle - changes the colour of a pixle, using rgb values

Graphics library usage:
    spawnwindow:
        creates a window that has a defualt white background, many windows can be spawned at the same time. The windows cannot be reized after creation
        usage: g:spawnwindow:<width>:<height>:<window id>   width and height are the number of pixles the window dimesions should be. The window id is a string that the window can be reffered to by other things

    changepixle:
        changes the state of a pixle at a certain x,y coord to any colour in the rgb range
        usage: g:changepixle:<window id>:<x>:<y>:<r>:<g>:<b>   window id is the string used as the name at window creation, x & y is the position of the pixle to be changed. r, g, b are the the red, green, and blue values that the pixle should take
